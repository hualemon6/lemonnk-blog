# 地图 + 液态玻璃全站重构

2026-09-16 确认方向。用户要求：以「时间树地图」为页面中心，四周面板不再固定，而是可拖拽、可吸附、可脱离、可记忆位置的液态玻璃浮窗。全站重构，文章在浮窗内阅读。

替代 2026-09-16 的横向经历面板改版（`horizontal-journey-design.md`）。

## 决策记录

| 项 | 决定 |
|---|---|
| 地图空间逻辑 | 多分区地图（楼层式） |
| 分区 | 分类四块地：学习 / 科研 / 项目 / 生活 |
| 楼层 | 年份；无日期的项目进「项目集」常设层 |
| 浮窗 | 完全自由拖拽 + 吸附 + 位置记忆 |
| 覆盖范围 | 全站所有页面；文章在浮窗里读 |
| 架构 | 静态多页（Astro 路由保留）+ 地图共用 + 位置记忆 |
| 移动端 | 本轮不做 |
| 材质来源 | awesome-design-md 的 `design-md/apple`（Liquid Glass 基线） |
| 技术路线 | SVG 地图层 + DOM 浮窗层 |

## 材质：Apple 基线 + 液态三件套

Apple 官方玻璃基线 `saturate(180%) blur(20px)`。在其上加三样：

1. **玻璃体** — `backdrop-filter: blur(28px) saturate(180%)` + 半透明填充
2. **高光边** — 顶部 1px 亮边、底部暗边，用 inset box-shadow 模拟菲涅尔
3. **流光** — 跟随鼠标的斜向高光，由 `--sheen-x` / `--sheen-y` 驱动；`prefers-reduced-motion` 下关闭

沿用 Apple token 语义：正文 17px、标题负字距、`rounded.lg = 18px`、`pill = 9999px`；**阴影只给实体，不给 chrome 本身堆叠装饰阴影**。

**前提**：地图底图必须有层次（渐变、网格、地块色块、光晕），否则玻璃折射不出内容，视觉上退化成白纸。

## 空间模型

### 坐标系：两层

```
视口
├─ #map-camera  translate(x,y) scale(k)   ← 相机层
│   └─ SVG .map-world  3080 × 2280 固定   ← 世界层（地块/干线/节点）
└─ .window-layer  position:fixed          ← 屏幕层（浮窗）
```

**铁律：地图动，浮窗不动。** 平移缩放地图时浮窗保持屏幕坐标不变。

### 分区几何

```
REGION 1240 × 820，世界 3080 × 2280，边距 170，间距 260
learning (170,170)     research (1670,170)
project  (170,1290)    life     (1670,1290)
```

分区内节点沿**回形产线**排布：`COLS = 3` 的网格，奇数行反向，每行不足则居中。节点块 168 × 104，内边距 X 170 / Y 150。

### 干线

中央竖脊 `x = 1540`，从 `y = 580` 到 `y = 1700`；四个分区内侧边中点各有支线接入，交点绘制换乘圆点。

### 楼层

按 `entry.date` 的年份分组；无日期记录归入 `collection` 层。**每个楼层单独计算分区内布局**，因此换层时节点重新落位。楼层顺序：年份降序，`collection` 最后。默认楼层取最新的年份层。

### 节点

| 状态 | 表现 |
|---|---|
| 默认 | 圆角方块，分类色 12% 填充 + 分类色描边 |
| 有配图 | 显示缩略图 |
| hover | 上浮 + 亮边 + DOM 提示卡 |
| 选中 | 分类色实心 + 外发光环 |
| 未读 | 右上角暖色圆点 |

LOD 按相机缩放分三级：`far` 只显示色块 / `mid` 加日期 / `near` 加缩略图与标题。

### 相机

滚轮以指针为锚点缩放（0.4× ~ 2.5×）；拖拽空白平移；双击分区 fit；右下角控件 ＋/−/适应/复位；键盘方向键平移、`0` 复位；空闲视差在 `reduced-motion` 下关闭。

## 浮窗系统

### 窗口清单

| id | 默认锚位 | 内容 |
|---|---|---|
| `identity` | 左上 | 头像、LemonNK、南大智科、外链 |
| `legend` | 左上（identity 下方） | 四个分类开关 + 条数 |
| `stats` | 顶部居中 | 条数 / 年份 / 阅读时长 |
| `detail` | 底部居中 | 选中节点的标题、日期、摘要、跳转 |
| `recent` | 右上 | 最近一篇文章 |
| `list` | 右上 | 归档 / 标签 / 项目 列表 |
| `about` | 居中 | 关于我 |
| `reader` | 居中 | 文章正文 |

`zoom` 控件与导航胶囊属于 chrome，固定不可拖。

### 拖拽

整窗空白处可抓取（按钮、链接、滑块自动排除）。拖动中提升 z-index、`scale(1.01)`、阴影加深、流光跟随。移动用 `translate3d`，`will-change` 仅在拖动期间挂载。

### 吸附

视口边缘 < 24px 贴边；窗口之间边缘 < 8px 对齐；吸附时显示提示线；按住 `Alt` 禁用吸附。

### 持久化

`localStorage` key `lemonnk:map:v1`，存每个窗口的 `{x, y, collapsed, closed, z}`。位置变更即写入。窗口不可被拖到完全离开视口（始终保留 48px 可见）。

### 收纳

窗口右上角三个钮：收起 / 展开 / 关闭。关闭的窗进入底部「窗柜」，点击唤回。导航胶囊内提供「复位布局」。

### 层级

```
50 菜单下拉
40 导航胶囊 · 缩放控件
30 阅读窗
20 拖拽中 / 刚聚焦的窗
10 常驻浮窗
 0 地图
```

### 性能与无障碍

同时最多 4 个窗启用 `backdrop-filter`，超出的降级为不透明填充；拖动时被拖窗降一档模糊。所有窗可 Tab 聚焦，方向键微调位置，`Esc` 关窗。尊重 `prefers-reduced-motion`。

### 与设计稿的偏差（均为实现时的修正）

1. **楼层不做层间过渡动画，改为「高亮当前层 + 相机 fit + 其余淡化」。** 原因：层间过渡需要每层独立布局，会导致同一分区在不同楼层节点位置不同，切换时视觉跳变；改为单次布局 + 淡化，任何楼层下节点都不重叠。
2. **地图提示卡与吸附提示线放在 `MapShell` 而非 `MapStage` 内。** 原因：`.map-stage` 有 `z-index: 0`，形成层叠上下文，其子元素无法盖过浮窗层。
3. **浮窗默认尺寸与锚位集中到 `WINDOW_SPECS`。** 未做浮窗缩放（只能拖拽 / 收起 / 关闭）。
4. **阅读窗固定 760px 宽，正文最高 `min(78vh, 820px)`。**
5. **窗柜改为常驻开关（不是仅列已关闭的窗）**，因为「复位布局」按钮需要一个永久的落脚点，且 `aria-pressed` 能表达开合状态。
